# ServerQuit

*register actions to be taken when a server quits*

**Related:** [Server](../Classes/Server.md), [ServerBoot](../Classes/ServerBoot.md), [ServerTree](../Classes/ServerTree.md), [ShutDown](../Classes/ShutDown.md)

**Categories:** Control

## Description

The singleton ServerQuit provides a place for registering functions and objects for events that should happen when a given server quits.
See [AbstractServerAction](../Classes/AbstractServerAction.md) for usage.
