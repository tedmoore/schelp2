## Instance Methods


### `add`
Add a SynthDesc to this SynthDescLib. Doing this triggers an update message with the key `\synthDescAdded` for any dependants this lib may have. See [Object#Dependancy](../Classes/Object.md#dependancy).**Arguments:**

| Argument | Description |
|----------|-------------|
| `synthdesc` | The [SynthDesc](../Classes/SynthDesc.md) to be added. |
