# ServerBoot

*register actions to be taken when a server has booted*

**Related:** [Server](../Classes/Server.md), [ServerQuit](../Classes/ServerQuit.md), [ServerTree](../Classes/ServerTree.md), [StartUp](../Classes/StartUp.md)

**Categories:** Control

## Description

The singleton ServerBoot provides a place for registering functions and objects for events that should happen when a given server has booted.
See [AbstractServerAction](../Classes/AbstractServerAction.md) for usage.
