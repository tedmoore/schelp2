# ServerStatusWatcher

*Observes and updates Server status*

**Categories:** Server

**Related:** [Server](../Classes/Server.md)

## Description

An object that observes a [Server](../Classes/Server.md) object by managing status requests and updates. ServerStatusWatcher is a client-side server implementation detail, and users are not expected to need to use it directly. A Server's status watcher can be accessed via [Server#-statusWatcher](../Classes/Server.md#-statuswatcher).
