# BEQSuite

*Base class for B Equalization Suite*

**Categories:** UGens>Filters>BEQSuite

## Description


**[BLowPass](../Classes/BLowPass.md)**
: 12dB/oct rolloff - 2nd order resonant Low Pass Filter

**[BLowPass4](../Classes/BLowPass4.md)**
: 24dB/oct rolloff - 4th order resonant Low Pass Filter (pseudo UGen)

**[BHiPass](../Classes/BHiPass.md)**
: 12dB/oct rolloff - 2nd order resonant Hi Pass Filter

**[BHiPass4](../Classes/BHiPass4.md)**
: 24dB/oct rolloff - 4th order resonant Hi Pass Filter (pseudo UGen)

**[BPeakEQ](../Classes/BPeakEQ.md)**
: Parametric Equalizer

**[BLowShelf](../Classes/BLowShelf.md)**
: Low resonant Shelf

**[BHiShelf](../Classes/BHiShelf.md)**
: High resonant Shelf

**[BBandPass](../Classes/BBandPass.md)**
: Band Pass Filter

**[BBandStop](../Classes/BBandStop.md)**
: Band Reject Filter

**[BAllPass](../Classes/BAllPass.md)**
: All Pass Filter


The B equalization suite is based on the Second Order Section ([SOS](../Classes/SOS.md)) biquad UGen.
SC3 port and coding - blackrain 06.17.2005
SC3 plugin UGens - Joshua Parmenter 06.22.2005
Some ideas from *"Cookbook formulae for audio EQ biquad filter coefficients"* by Robert Bristow-Johnson.
