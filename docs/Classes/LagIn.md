# LagIn

**Related:** [In](../Classes/In.md), [InFeedback](../Classes/InFeedback.md)

## Description

Read a control signal from a bus with a lag.


## Class Methods


### `kr`
**Arguments:**

| Argument | Description |
|----------|-------------|
| `bus` | The index of the bus to read in from. |  
| `numChannels` | The number of channels (i.e. adjacent buses) to read in. You cannot modulate this number. |  
| `lag` | Lag factor. |
