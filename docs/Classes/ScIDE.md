# ScIDE

*interaction with the Qt IDE*

**Categories:** Frontends

**Related:** [Document](../Classes/Document.md)

## Description

The ScIDE class contains a number of class methods for interaction with the Qt IDE. Most users won't need to access these methods directly. For example, the [Document](../Classes/Document.md) class wraps most of the document-related functionality.
There's no use calling *new on this class. It has no instance methods!
