# Color groups

**Categories:** GUI>Accessories

*A list of color groups within a palette, and their meaning*

A palette (see [QPalette](../Classes/QPalette.md)) consists of colors assigned to various color roles (see [palette_color_roles](../Reference/palette_color_roles.md)) within the three color groups. The following is a list of possible symbols to denote color groups, and their meanings.
| **Group** | **Meaning** | 
| --- | --- || 'active' | Contains colors used by views on the active window. | | 'inactive' | Contains colors used by views on inactive windows. | | 'disabled' | Contains colors used by disabled views. | | 'normal' | A synonym for 'active'. |
